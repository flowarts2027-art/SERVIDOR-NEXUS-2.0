## Protocolo de medição
1. Para cada publicação, persistir cliente_id, media_id, permalink, data, tipo (Reel/carrossel/imagem/story), campanha, assunto, CTA, versão da arte, referência do arquivo, estilo visual e público-alvo.
2. Coletar via integrações Meta autorizadas alcance, visualizações, tempo de exibição quando disponível, curtidas, comentários, salvamentos, compartilhamentos, visitas e seguidores atribuídos quando disponíveis; registrar indisponibilidade explicitamente.
3. Comparar peças de mesma categoria e janela de maturação (24h, 72h, 7 dias). Priorizar alcance de não seguidores, retenção, compartilhamentos e contatos/conversões rastreáveis. Nunca atribuir vendas sem evidência.
4. Nilo gera hipótese com nível de confiança; Creator/Designer fazem testes controlados de gancho, formato e estilo; Clara revisa integridade visual; Dante aprova recomendações.
5. Salvar relatório datado em docs/nexus-memory/clientes/flow-arts/analytics/ e atualizar este índice somente após dados verificados. Separar clientes rigidamente.
6. O ChatGPT deve consultar este arquivo e os relatórios datados antes de gerar campanha. O arquivo no GitHub é memória compartilhada consultável, NÃO atualização automática da memória interna do ChatGPT.
7. Não publicar automaticamente, não alterar campanhas existentes, não usar dados de outros clientes para treinar padrões da Flow Arts.

## Pendências técnicas
Automatizar coleta periódica, vincular cada mídia ao arquivo visual e integrar geração/revisão dos agentes. Este documento estabelece a regra, não comprova que o ciclo automático já está operacional.
